# Completed trusted-change package

This example is a **sanitized replay** of a real Leanforge repository change. It shows the user-owned
artifacts that should remain after a successful cycle: an approval-ready contract summary, the actual
change identity, captured verification, remaining risk, and an integration choice.

It is **not installed-host execution evidence**. The change was performed and verified in a local Git
workspace, but this public example does not claim that an installed Claude Code or Codex plugin loaded
the workflow. It also **does not establish Time to Trusted Change**, token savings, lower question count,
or a general quality improvement.

- [Approved contract summary](contract.md)
- [Final trusted-change result](result.md)

The example deliberately omits raw prompts, private paths, credentials, and full logs. Exact commands,
exit codes, commit identities, and the unresolved host-evidence boundary remain visible.
